# Guardian Program Station

[![Cross-Platform CI](https://github.com/CodeVault-netizen/Guardian-Program-Station/actions/workflows/ci.yml/badge.svg)](https://github.com/CodeVault-netizen/Guardian-Program-Station/actions/workflows/ci.yml)

A tree-based project structure manager with a cross-platform CLI
(`Guardian.ProgramStation.Cli`) that shares the same Application use cases
as the Avalonia GUI. The CLI is verified on Windows, Ubuntu Linux and macOS
by GitHub Actions.
